# Baha Plus TV

面向低性能安卓电视与电视盒子的巴哈姆特动画疯第三方客户端。使用 Kotlin、Android 原生 View／RecyclerView 与 Media3，支持方向键、确认键和返回键操作。最低系统以 Android 7.0／API 24 为基线。

本项目依据 Baha-Plus 的业务与官网适配器实现，保留其 MIT 许可证。界面为电视重新设计，使用系统字体、静态海报、清晰焦点和固定侧栏。

## 首版范围

| 项目 | 行为 |
| --- | --- |
| 首页 | 左侧导航、海报网格；官方历史中的继续观看优先展示 |
| 搜索 | 官方搜索接口，合并简体输入与繁体转换后的结果 |
| 详情 | 官方简介、制作信息与虚拟化选集列表 |
| 账号 | 单账号，优先手机扫码授权；保留官方网页登录与遥控光标 |
| 追番 | 经官方页面控件更新，成功后重新读取官方收藏 |
| 历史 | 从官方会话读取；不建立独立本地续播记录 |
| 正片 | 官方网页完成广告、年龄、账号及地区验证后交给 Media3 |
| 同步 | 将原生播放器的实际时间回传给官方回调；会话拒绝或失联时暂停 |
| 连播 | 默认自动播放同一作品下一集，可关闭 |
| 画质 | 默认自动，可选当前会话允许的画质并保存偏好 |
| 语言 | 默认简体中文，可切换繁体；片名与简介保留官方原文 |
| 更新 | 启动时静默检查 GitHub 正式发版；设置内可手动检查，有新版时由用户选择前往 GitHub 下载 |

弹幕、下载、投屏和评论互动不在本次首版实现范围。会员、地区、设备与广告策略由原站处理。

应用启动后在后台检查本仓库的最新正式 Release；无更新或检查失败时不提示。有更新时显示当前版本、最新版本和发布说明，可以取消，也可以选择“前往 GitHub 下载”打开对应发版页面。设置中的“检查更新”使用相同弹窗；手动检查无更新时提示“无更新”，网络失败时提示稍后重试。检查不会阻塞启动，播放、登录或应用在后台时会延后展示结果。电视没有浏览器时会展示发版地址，供其他设备访问。

## 遥控器

播放控制条隐藏时：

- 确认：播放／暂停。
- 左／右：每次快退／快进 10 秒。
- 上／下：显示控制条。

控制条显示后，方向键移动焦点，确认执行操作。返回先收起控制条或选集面板，再返回详情。详情返回列表时恢复选中位置。

选择“登录账号”会显示二维码，用手机相机扫描后，在巴哈姆特官方网页完成登录并确认授权。二维码有效期由官方返回，当前约为 3 分钟；过期后用遥控器选择“刷新二维码”。二维码在电视本地生成，确认后由同一个官方 WebView 会话接收 Cookie，再读取官方身份并同步追番与历史。后台暂停轮询，返回或切换登录方式会停止当前请求。手机无需安装本项目的配套 App。

扫码页保留“使用账号密码登录”。登录／验证网页顶部提供完成、刷新及遥控光标入口。光标模式用方向键移动、确认点击、返回退出；移到页面上／下边缘继续按方向键可以滚动。输入使用电视系统键盘。用户已反馈模拟器账号功能正常；官方验证码、两步验证与具体电视输入法的可操作性仍需在目标设备验证，测试范围见 [扫码登录记录](docs/qr-login.md)。

播放时出现官方年龄提示，底部会显示电视大按钮，并自动聚焦“同意并继续”；左右键切换选项，确认键提交，选择“不同意，返回详情”或按返回键可退出。分级标志与警告保留在官方页面中，确认操作点击当前页面的官方同意按钮。若官网按钮暂不可用，可使用顶部刷新入口。

官方广告显示跳过倒计时时，底部只显示“广告 X 秒”；官网允许跳过后，电视“跳过广告”按钮启用并自动获得焦点，按确认键即可点击官方跳过按钮。年龄确认和广告页面顶部提供返回与刷新；遥控光标入口仅保留在登录等官方验证页面。

## 日志与反馈

普通用户可在 **设置 → 日志与反馈** 中开始记录，返回复现问题后再停止记录。支持预览／复制、手机扫码下载、系统分享和清除日志，无需开发者模式、ADB 或额外存储权限。

选择“发送日志与反馈”会停止采集并生成文本报告。手机与电视连接同一局域网后扫描二维码，下载 `.txt` 日志，再通过页面中的 GitHub Issues 入口描述问题、附上文件或粘贴日志；也可用已有联系方式发送给开发者。GitHub 提交需要账号。电视保持下载窗口打开，链接最多有效 10 分钟；关闭窗口或应用退到后台会停止下载。扫码下载只把日志交给手机，实际反馈由用户确认提交。

日志默认关闭，仅保存应用事件、错误码、播放状态和设备版本，轮转上限为 512 KiB；不采集系统 logcat、账号标识、Cookie、密码、授权二维码、搜索词或媒体 URL。应用进程结束后不自动继续采集，已有记录仍可取回。详见 [日志与反馈说明](docs/diagnostics.md)。

## 低资源模式

默认开启：

- 海报内存缓存 8 MiB、磁盘缓存 12 MiB；通常模式为 20／32 MiB。
- 图片按长边上限采样，低资源模式为 320 像素、通常模式为 512 像素，使用 RGB565；解码与网络在受限工作队列执行，离开列表时取消未完成的封面请求。
- RecyclerView 复用卡片，减少预取与离屏缓存，关闭列表动画；低资源模式的遥控焦点滚动直接定位，通常模式保留平滑滚动。
- 正片接管后卸载网页媒体源和多余 DOM，保留官方政策与进度回调。
- Media3 不保留回看缓冲，缓冲目标字节为 16 MiB；通常模式为 32 MiB。
- 不请求后台播放服务；应用进入后台时暂停。
- 原生播放控制条隐藏时停止刷新进度界面，官方进度与会话确认仍按实际播放时间回传。

这些是资源预算配置，不代表已经测得的进程内存或帧率。系统 WebView、解码器和图形缓冲另有开销。低资源模式与视频画质独立。

## 构建

需要 JDK 17 或 21、Android SDK Platform 36 与 Build Tools 35.0.0。Gradle Wrapper 固定为 8.14.3，并校验分发包。

已有 SDK 时，在项目根目录新建不提交的 `local.properties`：

```properties
sdk.dir=D\:/Android/Sdk
```

Windows PowerShell：

```powershell
.\tools\Build.ps1
```

构建脚本执行 `testDebugUnitTest lintDebug assembleDebug`，将调试 APK 与 SHA-256 复制到 `artifacts/`。优先使用已有 Gradle 分发包；构建缓存和 Android 用户目录放在项目 `.tools/` 下。

需要下载项目专用 SDK 时，先审阅 [初始化脚本](tools/Bootstrap-Android.ps1)：

```powershell
.\tools\Bootstrap-Android.ps1
```

脚本从 Google 官方源下载并校验命令行工具，在 `.tools/android-sdk` 下安装编译所需组件，并在终端提示 SDK 许可。明确接受这些许可后，可使用 `-AcceptSdkLicenses` 自动回答。脚本不修改系统 PATH，不创建系统任务。

也可以使用标准 Wrapper：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

当前依赖没有配置仅限 64 位的 ABI 过滤；打包时应检查 APK 中任何新增原生库是否同时提供 `armeabi-v7a`。首要目标设备是 32 位运行环境。

## 离线检查

需要 Node.js 18+ 与 Python 3：

```powershell
node --test tests/*.test.cjs
python tools/check-project.py
```

JVM 测试位于 `app/src/test`，覆盖 URL 来源、原生播放清单、进度边界与扫码授权链接；只有 Android 构建任务成功执行后才能报告其结果。

## 开源与会话边界

官网适配器来自 Baha-Plus，移植时修改了 TV 广告控件的显示行为；TV 搜索、追番命令与方向导航另行实现。原项目 MIT 许可随源码与 APK 一起分发，见 [LICENSE](LICENSE) 与 [NOTICE](NOTICE)。

WebView 消息只接受官方来源的主框架，并校验文档与请求标识；旧 WebView 使用主框架队列，不添加对所有 iframe 暴露的 JavaScriptInterface。主页面导航限制为官方 HTTPS 域名，原生 HLS 源限制为当前授权会话中的指定 CDN。应用不保存账号密码、媒体源 URL或独立本地观看断点。Cookie 会话由系统 WebView 管理，退出登录清除该会话。
