## 功能

### 在电视上发现想看的动画

- 在首页浏览新番、热门作品和最新上架的动画。
- 搜索感兴趣的作品，支持简体与繁体中文关键词。
- 查看作品介绍和剧集列表，选择想看的集数。
- 为电视设计的侧栏、海报网格和醒目焦点，方向键、确认键与返回键即可完成主要操作。

### 继续你的追番日常

- 用手机扫描电视上的二维码，在巴哈姆特官方网页登录并确认授权。
- 登录后查看官方账号的追番收藏与观看记录。
- 在作品详情页加入或取消追番，从观看记录继续未看完的剧集。
- 无需自建服务器，也不需要安装配套手机 App。

### 按自己的习惯观看

- 使用遥控器播放、暂停，每次快进或后退 10 秒。
- 在播放控制条中切换画质、倍速和集数。
- 默认自动播放同一作品的下一集，也可在设置中关闭。
- 默认自动选择画质，可手动选择官方提供的档位并记住偏好。
- 应用进入后台时暂停播放。

### 照顾性能有限的电视

- 默认开启低资源模式，减少界面动画、封面尺寸、缓存与预加载。
- 低资源模式与视频画质分开设置，可以按电视的实际表现调整。
- 支持简体中文与繁体中文界面，片名和简介保留官方原文。
- 启动后自动检查更新，发现新版时提示；也可在设置中手动检查。
- 遇到问题可直接在电视上记录日志，再用手机扫码取走并反馈，无需连接电脑。

## 下载安装

请前往 [GitHub Releases](https://github.com/InternetBugs/Baha-Plus-AndroidTV/releases) 选择版本，下载附件中的 **`.apk` 安装包**。

- **设备要求：**运行 Android 7.0 或更高版本的安卓电视、Android TV 或电视盒子。
- **安装方式：**将 APK 通过 U 盘或文件传输工具传到电视，用电视上的文件管理器打开，按系统提示允许安装来自该来源的应用。
- **安装完成：**在电视应用列表中打开 **Baha Plus TV**，即可开始浏览和观看。

应用针对电视与遥控器设计。不同设备的安装入口可能不同，是否支持安装 APK 请以设备系统为准。

以后更新时，可以在 **设置 → 检查更新** 查看新版本，按提示前往 GitHub 下载并安装。电视没有浏览器时，可在手机或电脑上打开发版页面，再把安装包传到电视。

想自行构建的用户可以参考 [开发与构建](docs/development.md)。

## 开始使用

1. 打开 Baha Plus TV，在首页浏览动画，或通过左侧的“搜索”寻找作品。
2. 选择作品查看介绍和剧集列表，再选择一集开始播放。遇到分级提示或广告时，按画面提示操作。
3. 想使用追番与观看记录时，选择“登录账号”，用手机相机扫描电视二维码，在官方网页完成登录和授权。
4. 登录后通过左侧的“追番”和“历史”查看收藏与观看记录，也可以在详情页管理追番。
5. 在“设置”中调整低资源模式、自动播放下一集和界面语言。

二维码过期后，选择“刷新二维码”即可重新扫码。账号输入、验证码和两步验证都在手机的官方网页完成。

## 遥控器操作

浏览页面时，用方向键移动焦点，确认键打开或选择，返回键回到上一层。

**正片播放且控制条隐藏时：**

| 按键 | 操作 |
| --- | --- |
| 确认键 | 播放／暂停 |
| 左键 | 后退 10 秒 |
| 右键 | 快进 10 秒 |
| 上键／下键 | 显示播放控制条 |
| 返回键 | 返回详情页 |

控制条显示后，用方向键选择播放、画质、倍速或选集等按钮，再按确认键操作。按返回键先关闭当前面板或控制条，再次按返回键退出播放。

## 常见问题

**需要登录才能使用吗？**

可以先以访客身份浏览、搜索和观看官方允许播放的内容。追番与个人观看记录需要登录巴哈姆特账号；具体播放资格由官方决定。

**为什么有广告，有些作品无法播放或没有高画质？**

本项目保留官方广告流程。作品是否可播放、可用画质、会员权益、年龄验证和地区限制均由官方决定，请按界面提示操作。需要家长密码等暂未支持的额外验证时，应用会提示并停止播放。

**追番和观看进度会同步吗？**

应用使用官方账号的追番与观看记录，并向官方回报播放进度。账号同步与不同电视的播放表现仍在持续验证，跨设备续播请以官方端实际显示的记录为准。列表没有更新时，可尝试 **设置 → 刷新官方内容**。

**电视比较卡，应该怎么设置？**

先保持 **设置 → 低资源模式** 开启，它主要减少界面的资源占用，不会直接降低视频画质。如果播放时频繁缓冲，可在控制条中选择较低画质，并检查网络连接；能否流畅播放也取决于电视的解码能力。

**为什么更新时提示无法安装或签名不一致？**

先确认下载的是 `.apk` 文件，设备系统为 Android 7.0 或更高版本。正式签名版本通常可以覆盖升级；本地调试包以及早期 `v0.1.0`／`v0.1.0-qr.1` 测试包使用不同签名，切换到正式版时需要先卸载旧应用。**卸载会清除本机登录状态与设置，重新安装后需要再次扫码登录。**

**扫码登录失败怎么办？**

保持电视扫码页打开，在手机官方网页完成登录并确认授权。如果二维码过期，选择“刷新二维码”后重新扫码；仍然失败时，可返回后重新打开“登录账号”。不需要在电视上输入账号密码。

**遇到问题怎么提供日志？**

打开 **设置 → 日志与反馈**（繁体界面为“設定 → 日誌與回報”）：

1. 选择“开始记录”，返回应用，重复出现问题的操作。
2. 回到日志页面，选择“停止记录”，再“预览日志”。
3. 选择“发送日志与反馈”，让手机与电视连接同一局域网，扫描二维码并下载 `.txt` 日志。
4. 在手机页面中打开 GitHub Issues，描述问题并附上文件，或通过已有联系方式发给开发者。GitHub 提交需要账号；扫码下载日志后，还需要自行提交反馈。

下载时请保持电视上的传送窗口打开，链接最多有效 10 分钟。手机无法连接时，可尝试页面中的“系统分享文件”，或复制日志内容。

日志默认关闭，不会自动上传，也不记录账号、密码、Cookie、搜索词或播放链接。应用重开后不会自动继续记录，已有日志仍可取回；可以随时选择“清除日志”。更多说明见 [日志与反馈](docs/diagnostics.md)。
