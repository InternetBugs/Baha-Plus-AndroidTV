# Baha Plus TV 0.4.2

发布日期：2026-11-18，Asia/Taipei。版本：`0.4.2`／versionCode 7。

- 新增「时间表／時間表」页面：按周一至周日查看本季新番的更新时间，默认选中台湾当天，方向键切换星期，选中项在页面重建后保留。列表按 `HH:mm` 升序排列，官方未提供时间的条目排在最后并显示「待定」；点开条目直接进入详情。
- 时间表只读取官方 `newAnime` 的 `week` 与 `upTimeHours`，热门与最新上架区块不产生时间条目；同一部作品同时出现在多个区块时保留最早取得的时间。
- 统一所有 gamer.com.tw／bahamut.com.tw 请求的 User-Agent：官网会话、扫码登录 WebView、原生 API、播放器、详情接口与海报下载共用同一个浏览器标识，此前详情接口与海报会发送 Android 默认标识。GitHub 更新检查仍使用应用自己的标识。
- 修正时间表的台湾星期换算，避免周一被显示为周二。

最低支持 Android 7.0／API 24。本次改动通过单元测试（112 项）、适配器测试与项目资源检查；时间表页面和统一后的 User-Agent 尚未在电视真机或模拟器上回归，实际节目时间以上架公告为准。

**安装说明：**下载 `BahaPlusTV-0.4.2-release.apk` 侧载。已安装正式签名的 `0.2.0`／`0.3.0`／`0.3.1`／`0.4.0` 可直接覆盖升级，保留本地登录会话与设置。本地 `debug` 包及早期 `v0.1.0`／`v0.1.0-qr.1` 测试包使用不同签名，需先卸载再安装；卸载会清除本地登录会话与设置，安装后需重新扫码登录。
