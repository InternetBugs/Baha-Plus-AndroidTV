# Baha Plus TV 0.4.0

发布日期：2026-11-14，Asia/Taipei。版本：`0.4.0`／versionCode 5。

- 首页、搜索、番剧详情、追番、观看历史与播放迁移到原生 HTTP，浏览和播放不再依赖官网播放器及业务 WebView 桥接。官方授权、分级确认、广告和观看进度回报继续按官方规则处理。
- 新增原生弹幕显示，支持滚动、顶部和底部弹幕。开关与设置位于播放进度条下方，可用遥控器调整字号、不透明度、显示范围与弹幕类型，并保存偏好；电视端仅观看弹幕。
- 番剧详情与选集页面新增官方评分表，展示平均分、评价人数以及五星到一星的分布。评分异步加载，不影响选集和播放。
- 修复扫码成功后仍显示未登录的问题，将账号身份核对与追番、历史同步分开处理；列表同步失败不再撤销已经确认的登录。
- 修复取消追番已在官方生效、界面却报错或显示旧状态的问题，变更后重新核对官方状态。
- 登录统一为手机扫码授权，移除电视端账号密码输入入口。二维码过期后可在电视上刷新。
- 沿用 Baha Plus 品牌图标，更新电视应用图标与横幅，并重写面向普通使用者的 README，补充安装、遥控器操作和问题反馈说明。

最低支持 Android 7.0／API 24，默认开启低资源模式。安装包由 GitHub Actions 执行适配器与单元测试、资源检查、Release Lint 和构建，使用既有发布密钥签名，附件提供 SHA-256 校验文件。

此前的独立 x86 模拟器已分别验证原生浏览与播放、扫码入口、弹幕和评分表，账号识别与追番状态修复也有现有登录会话的回归记录。这些记录对应各功能的开发构建；目标 32 位 ARM 电视、此次整合版本的整集播放与跨设备同步仍需继续验证。详细范围见 [原生 HTTP 迁移](https://github.com/InternetBugs/Baha-Plus-AndroidTV/blob/v0.4.0/docs/native-http-migration.md)、[弹幕说明](https://github.com/InternetBugs/Baha-Plus-AndroidTV/blob/v0.4.0/docs/danmaku.md)与[详情及评分表](https://github.com/InternetBugs/Baha-Plus-AndroidTV/blob/v0.4.0/docs/native-details.md)。

**安装说明：**下载 `BahaPlusTV-0.4.0-release.apk` 侧载。已安装正式签名的 `0.2.0`／`0.3.0`／`0.3.1` 可直接覆盖升级，保留本地登录会话与设置。本地 `debug` 包及早期 `v0.1.0`／`v0.1.0-qr.1` 测试包使用不同签名，需先卸载再安装；卸载会清除本地登录会话与设置，安装后需重新扫码登录。
