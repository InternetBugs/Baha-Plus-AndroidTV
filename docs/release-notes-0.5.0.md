# Baha Plus TV 0.5.0

版本 `0.5.0`／versionCode 9。

### 界面与遥控器体验

- **全新播放控制条**：改用底部半透明渐变遮罩替代纯黑块，大幅减少对画面的遮挡；顶部单行显示片名、当前集数与时间，画质按钮实时展示当前分辨率（如 `自动 · 1080p`）；控制条隐藏时按左右键快进/后退新增轻量 OSD 提示与迷你进度条。
- **统一深色电视弹窗**：画质、倍速、选集、分级确认、完整简介、账号管理、更新提示与诊断预览统一为深海蓝 + 青绿高亮焦点风格，遥控器远距离焦点更清晰；禁用按钮增加明确的置灰样式与不可聚焦保护。
- **详情页整页滚动与智能续播**：头部简介、官方评分与选集整合为统一滚动视图，浏览选集时可完整利用屏幕高度；长番（超过 30 集）自动提供分段选集标签；主操作按钮按观看记录自动显示“继续播放 第 X 集”并在选集中高亮；“完整简介”补全全部本地化制作元数据。
- **首页、时间表与搜索增强**：
  - 首页侧栏新增图标与选中指示条，压缩顶部标题栏、封面圆角裁切并将观看进度条叠加在封面底边，一屏完整呈现两行番剧卡片。
  - 时间表切换星期改为就地刷新并保留返回焦点与滚动位置，行尾展示“已追番”及今日“已更新 / 待更新”状态标签。
  - 搜索页新增“清空”按钮与本地最近搜索历史标签（最多 8 条，可一键清除）。
  - 设置页开关切换改为就地更新，不再闪烁或跳回顶部。

### 性能与稳定性修复

- **修复并发加载瓶颈**：修正 `PosterLoader`、`NativeTaskLoader` 与 `AnimeDetailLoader` 线程池配置导致的单线程排队问题；海报加载新增同 URL 并发去重、节流磁盘清理与真实 LRU，移除主线程 `purge()`；二维码改用最小模块尺寸生成并在诊断页移至后台线程。
- **优化弹幕流畅度与密度**：按 VSync 稳定 60fps / 30fps（低资源模式）帧率，滚动弹幕在安全间距后释放轨道入口以提升同屏弹幕容量，并补充圆角描边。
- **修复若干边界问题**：拆分首页与搜索的独立加载状态避免串扰；修复正片缓冲时状态文案过时、与转圈重叠及缓冲误弹出完整控制条的问题；修复广告跳过按钮焦点顺序与间距；补充快进进度上报防抖与小容量回看缓冲；修复时间表与弹幕诊断日志白名单漏项；合并登录/同步阶段冗余的账户页请求。

最低支持 Android 7.0／API 24。本次版本已通过 124 项 JVM 单元测试、WebView 74 适配器测试、Android Release Lint 及项目资源检查，并在 Android TV 11（API 30）模拟器上验证首页、时间表、搜索、详情、弹窗、正片播放、弹幕、设置与诊断界面。

**安装说明：**下载 `BahaPlusTV-0.5.0-release.apk` 侧载。已安装正式签名版本的用户可以直接覆盖升级，保留现有登录会话与设置。
