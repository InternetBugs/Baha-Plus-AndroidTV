# Baha Plus TV 0.1.0 扫码登录测试版

发布日期：2026-11-13，Asia/Taipei。GitHub 标签：`v0.1.0-qr.1`。

“登录账号”现在优先显示手机扫码页。手机扫描后进入巴哈姆特官方网页完成登录与授权，电视通过同一个官方 WebView 会话接收登录结果，并重新读取官方身份、追番和历史。手机无需安装本项目的配套 App；账号密码登录与遥控光标入口继续保留。

- 复用官方授权申请与状态轮询接口，二维码在电视本地生成。
- 根据服务器期限显示倒计时，支持过期刷新、网络重试和取消。
- 进入后台暂停轮询，返回或切换登录方式时取消当前请求；旧响应无法覆盖新二维码。
- 2026-11-13，酥鱼在交互模拟器中测试后反馈“账号功能完全正常”。

已通过 Android 编译、5 项 JVM 单元测试、20 项 Node.js 测试和项目检查；Lint 为 0 错误、6 项既有警告。APK v2 签名与 16 KiB 对齐检查通过，包内没有原生 `.so` 库。官方真实浏览器验证及 Android TV 模拟器二维码显示记录见 [扫码登录记录](qr-login.md)。

用户反馈未附带每个账号子功能的独立操作记录。TCL 55Q9K 等目标 ARM 电视的登录、验证码、遥控输入、硬件解码、性能、音画同步及连续整集播放仍需实机验收。
