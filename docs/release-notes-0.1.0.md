# Baha Plus TV 0.1.0 测试版

面向低性能安卓电视与电视盒子的原生第三方客户端，最低 Android 7.0／API 24，默认开启低资源模式。采用 Kotlin、View／RecyclerView 与 Media3，核心界面支持遥控器方向键、确认键和返回键。

- 首页浏览、简繁搜索、番剧详情和选集。
- 单账号官方网页登录、原站追番与观看记录适配。
- 官方验证与广告后进入原生正片播放，支持暂停、前后 10 秒、授权画质、倍速及自动下一集。
- 简体／繁体界面、静态海报与低资源设置。

本版已在 Android TV Android 11／API 30、32 位 x86、2 GB 内存模拟器验证首页、遥控搜索、详情、官方年龄确认和广告、第 1／2 集原生播放、基础控制、后台暂停及快进后第 2 → 3 集自动切换。

本轮修复了遥控光标居中、首列返回侧栏、导航焦点被抢走和详情返回后的滚动位置恢复问题。4 项 JVM 单元测试、12 项适配器离线测试、Lint、APK v2 签名及对齐检查通过。

**仍需验收：**真实账号登录、验证码与两步验证、官方追番及进度写回、连续无快进看完一整集，以及 TCL 55Q9K 等 ARM 电视的硬件解码、性能和音画同步。模拟器测试不代表目标电视验收通过。
