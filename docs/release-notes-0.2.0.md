# Baha Plus TV 0.2.0

发布日期：2026-11-13，Asia/Taipei。版本：`0.2.0`／versionCode 2。

- 优化低资源模式下的遥控列表滚动，减少跨行移动焦点时的动画与绘制开销。
- 修正封面解码尺寸，降低海报内存占用；离开列表时取消未完成的封面请求，减少重复页面重建。
- 播放进度条区分已播放、已缓存和未缓存区域，方便查看缓冲情况。
- 播放控制菜单采用两行图标布局；控制条隐藏时停止刷新进度界面，减少后台界面开销，官方进度与会话确认继续回传。
- 官方年龄确认和广告页提供适配遥控器的大按钮；官网允许跳过广告后，可直接按确认键跳过。
- 减少旧版 WebView 在空闲、后台及原生播放时的无效消息轮询。

最低支持 Android 7.0／API 24，默认开启低资源模式。安装包由 GitHub Actions 构建并使用固定发布密钥签名，附件提供 SHA-256 校验文件。

**安装说明：**下载 `BahaPlusTV-0.2.0-release.apk` 侧载。早期 `v0.1.0`／`v0.1.0-qr.1` 测试包使用调试签名，安装本版前需先卸载旧应用；卸载会清除本地登录会话和设置，安装后需重新扫码登录。后续正式签名版本继续使用相同密钥。
