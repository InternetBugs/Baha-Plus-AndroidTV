# Baha Plus TV 0.3.1

发布日期：2026-11-13，Asia/Taipei。版本：`0.3.1`／versionCode 4。

- 修复部分旧版系统 WebView 无法显示番剧详情和选集的问题，补充应用适配脚本对旧语法和浏览器 API 的兼容处理。
- 新增官网播放脚本的客户端兼容转换：根据实际内核能否解析所需语法自动启用；支持时直接加载，不依赖固定版本分界或逐个脚本文件名单。
- 修复 WebView 83 缺少 `String.replaceAll` 导致的官网辅助脚本错误。转换保留原有严格模式、模块导入及官网播放逻辑，官方年龄确认、广告、账号与地区验证继续按原流程处理。
- 转换结果按源码内容缓存，减少重复编译。旧内核首次加载可能较慢；支持所需语法的内核不会创建编译器或加载兼容补丁。
- 对兼容处理后仍无法解析的官网主播放器提供明确提示，支持重试和返回详情。

独立 x86 访客模拟器已验证实际 WebView **83.0.4103.120** 下《黑色五葉草》170 集详情、第 1／2 集经过官方年龄确认和广告后的原生播放、暂停及返回选集；WebView **90.0.4430.91** 保持原始脚本加载并通过播放回归。目标 32 位 ARM 电视、真实账号、整集播放及 WebView 74 正片仍需验证，不能保证所有旧内核均可播放。详细范围见 [模拟器验证记录](https://github.com/InternetBugs/Baha-Plus-AndroidTV/blob/v0.3.1/docs/emulator-validation.md)。

最低支持 Android 7.0／API 24，默认开启低资源模式。安装包由 GitHub Actions 构建，使用既有发布密钥签名，附件提供 SHA-256 校验文件。

**安装说明：**下载 `BahaPlusTV-0.3.1-release.apk` 侧载。已安装正式签名的 `0.2.0`／`0.3.0` 可直接覆盖升级，保留本地登录会话与设置。本地 `debug` 包及早期 `v0.1.0`／`v0.1.0-qr.1` 测试包使用调试签名，与正式签名不同，需先卸载再安装；卸载会清除本地登录会话与设置，安装后需重新扫码登录。
