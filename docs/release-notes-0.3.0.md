# Baha Plus TV 0.3.0

发布日期：2026-11-13，Asia/Taipei。版本：`0.3.0`／versionCode 3。

- 新增启动时自动检查更新：发现 GitHub 正式新版后显示版本与更新说明，可取消或前往发版页面下载；没有新版或检查失败时不打扰使用。
- 设置新增“检查更新”入口，手动检查可查看新版、确认已是最新版本或获知网络检查失败。播放、登录及应用在后台时，自动更新提示会延后显示。
- 设置新增“日志与反馈”，支持开始／停止记录、预览／复制、清除和系统分享，普通用户无需开发者模式或 ADB 即可记录问题。
- 支持手机与电视连接同一局域网后扫码下载日志，再通过 GitHub Issues 或已有联系方式发送反馈。关闭下载窗口、应用进入后台或链接到期后，下载服务自动停止。
- 日志默认关闭，记录播放状态、应用事件、错误码和设备环境，轮转上限为 512 KiB；不记录账号标识、密码、Cookie、授权二维码、搜索词或媒体地址，也不自动上传。
- 新增功能均提供简体与繁体界面，并支持方向键、确认键与返回键操作。

最低支持 Android 7.0／API 24，默认开启低资源模式。安装包由 GitHub Actions 构建并使用固定发布密钥签名，附件提供 SHA-256 校验文件。

**安装说明：**下载 `BahaPlusTV-0.3.0-release.apk` 侧载。已安装正式签名的 `0.2.0` 可直接覆盖升级，保留本地登录会话与设置。早期 `v0.1.0`／`v0.1.0-qr.1` 测试包使用调试签名，升级前需先卸载旧应用；卸载会清除本地登录会话与设置，安装后需重新扫码登录。
