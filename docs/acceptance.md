# TV 安装与验收

以下项目尚未完成真机执行。只有记录实际设备与结果后才能标为通过。

## 安装前

```powershell
adb devices -l
adb shell getprop ro.build.version.sdk
adb shell getprop ro.product.cpu.abilist
adb shell dumpsys webviewupdate
```

核实 API 不低于 24、存在兼容的 WebView 提供程序，以及 APK 中任何原生库与设备 ABI 匹配。记录系统版本与 WebView 版本，不导出 Cookie、账号密码或验证码。

构建后安装：

```powershell
adb install -r artifacts/BahaPlusTV-0.1.0-debug.apk
adb shell am start -n app.bahaplus.tv/.MainActivity
```

调试包只用于侧载测试。正式发布的签名与分发应另行配置，不把密钥提交到仓库。

## 全程只使用遥控器

- [ ] 电视桌面可找到入口，启动后焦点可见。
- [ ] 左侧五项导航、账号入口和内容区域可往返。
- [ ] 首页连续滚动，打开详情后返回仍选中原卡片。
- [ ] 在靠后的集数上打开播放并返回，恢复该集位置；设置切换后保留当前设置项焦点。
- [ ] 遥控光标按一次返回只退出光标模式；播放中按一次返回只执行一层返回操作。
- [ ] 搜索键盘可仅用遥控器输入、删除、提交和关闭。
- [ ] 同一片名的简体和繁体输入可找到官方可用结果。
- [ ] 正常键盘及必要时的遥控光标能完成官方登录。
- [ ] 实际出现的年龄确认、邮箱／两步验证与人机验证可以完成；未触发的步骤记录为“未覆盖”。
- [ ] 冷启动登录态、会话失效重登与退出登录按实际表现记录。

## 观看与同步

- [ ] 广告与验证未完成时，原生播放器不开始正片。
- [ ] 记录当前账号可用画质，自动及手动画质切换正常。
- [ ] 连续播放一整集，音画同步，无持续掉帧或异常中断。
- [ ] 控制条隐藏时确认、左右及上下按约定工作。
- [ ] 控制条显示时方向键、倍速、画质与选集可用。
- [ ] 返回先收起面板，再回到详情；重复进出播放至少 10 次。
- [ ] 默认自动续集；关闭后停止在结束页；最后一集不跳到其他作品。
- [ ] 进入后台立即暂停，回来后可以手动继续。
- [ ] 正片接管后没有第二路网页音视频同时播放。
- [ ] 退出播放并重新进入，由官方恢复保存的续播点。
- [ ] 官方端能看到同一观看记录与追番变更；无法确认写回时不报告成功。
- [ ] 账号策略拒绝、设备锁、网络中断与网页渲染进程退出均能暂停、重试或返回。
