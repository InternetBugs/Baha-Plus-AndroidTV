# TV 安装与验收

以下项目尚未完成真机执行。只有记录实际设备与结果后才能标为通过。

## 安装前

```powershell
adb devices -l
adb shell getprop ro.build.version.sdk
adb shell getprop ro.product.cpu.abilist
adb shell dumpsys webviewupdate
```

核实 API 不低于 24、存在兼容的 WebView 提供程序，以及 APK 中任何原生库与设备 ABI 匹配。记录系统版本与 WebView 版本，不导出 Cookie、账号密码或验证码。

构建后安装：

```powershell
adb install -r artifacts/BahaPlusTV-0.1.0-debug.apk
adb shell am start -n app.bahaplus.tv/.MainActivity
```

调试包只用于侧载测试。正式发布的签名与分发应另行配置，不把密钥提交到仓库。

## 全程只使用遥控器

- [ ] 电视桌面可找到入口，启动后焦点可见。
- [ ] 左侧五项导航、账号入口和内容区域可往返。
- [ ] 首页连续滚动，打开详情后返回仍选中原卡片。
- [ ] 在靠后的集数上打开播放并返回，恢复该集位置；设置切换后保留当前设置项焦点。
- [ ] 扫码页按返回退出并恢复焦点；播放中按一次返回只执行一层返回操作。
- [ ] 搜索键盘可仅用遥控器输入、删除、提交和关闭。
- [ ] 同一片名的简体和繁体输入可找到官方可用结果。
- [ ] 登录仅显示二维码及刷新、返回按钮，简繁中文均没有账号密码登录入口；失败时可刷新重试。
- [ ] 手机扫码后在官方网页完成登录及实际出现的邮箱／两步验证与人机验证，电视自动核对身份并同步账号；未触发的步骤记录为“未覆盖”。
- [ ] 年龄提示出现后自动聚焦底部“同意并继续”；左右键可切换，等待时焦点保持，选择不同意或返回可退出；确认后进入官方后续流程，刷新及切集后重新检查。
- [ ] 冷启动登录态、会话失效重登与退出登录按实际表现记录。
- [ ] 启动自动检查更新时没有加载弹窗；无新版或断网时无提示。有新版时展示版本及发布说明，遥控器可取消、返回或选择“前往 GitHub 下载”打开对应发版页面。
- [ ] 设置的“检查更新”有新版时展示同一弹窗，无新版时提示“无更新”；断网或 GitHub 限流时提示失败，连续确认不重复请求，检查结束后可以重试。
- [ ] 设置的“日志与反馈”可用遥控器开始／停止记录；返回复现问题后仍有记录，开始新记录前说明会替换上次日志。
- [ ] 日志可预览、复制、导出；同一局域网手机扫码后可下载并前往 GitHub 附件反馈，或使用系统分享。关闭窗口、退到后台或到期后下载失效。
- [ ] 应用重开后采集关闭、旧日志仍可发送；清除后日志为空；报告没有账号、Cookie、搜索词、授权链接或媒体地址。
- [ ] 检查期间进入后台、登录或播放，不弹出更新提示；回到前台浏览时展示待处理结果。无浏览器时展示可在其他设备访问的发版地址。

## 观看与同步

- [ ] 广告与验证未完成时，原生播放器不开始正片。
- [ ] 广告倒计时期间跳过按钮不可用；官网允许跳过后自动聚焦电视“跳过广告”，确认键可执行；连续多段广告重新遵循各段倒计时。
- [ ] 记录当前账号可用画质，自动及手动画质切换正常。
- [ ] 连续播放一整集，音画同步，无持续掉帧或异常中断。
- [ ] 控制条隐藏时确认、左右及上下按约定工作。
- [ ] 控制条显示时方向键、倍速、画质与选集可用。
- [ ] 播放进度条以绿色显示已播放、浅灰色显示已缓存、深色显示未缓存；暂停时缓存条继续更新，快进退、切换画质或切集后按当前媒体刷新，时长未知时清空进度。
- [ ] 弹幕开关和设置位于进度条下方，方向键与确认键可调整字号、不透明度、显示范围和三种类型；展开后控制条保持可见，返回先收起设置并恢复焦点。
- [ ] 滚动／顶部／底部弹幕可见，暂停、缓冲、倍速、快进退、后台及切集后与媒体位置同步；开关和设置在切集与重启后沿用，界面没有发送入口。
- [ ] 弹幕空列表与加载失败分别提示，失败可单独重试，视频和官方进度上报继续；切集或离开后没有旧弹幕回填。接入细节见 [弹幕说明](danmaku.md)。
- [ ] 返回先收起面板，再回到详情；重复进出播放至少 10 次。
- [ ] 默认自动续集；关闭后停止在结束页；最后一集不跳到其他作品。
- [ ] 进入后台立即暂停，回来后可以手动继续。
- [ ] 正片接管后没有第二路网页音视频同时播放。
- [ ] 退出播放并重新进入，由官方恢复保存的续播点。
- [ ] 官方端能看到同一观看记录与追番变更；无法确认写回时不报告成功。
- [ ] 账号策略拒绝、设备锁、网络中断与网页渲染进程退出均能暂停、重试或返回。
